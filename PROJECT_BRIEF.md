# Project Brief: HotelHub (Hotel Booking MERN App)

## 1. Overview
* **Project Name:** Hotel Booking MERN App (HotelHub)
* **One-line Description:** Full-stack MERN hotel booking engine with room search, real-time availability, Clerk auth, and Stripe payments.
* **Target User:** Travelers looking for seamless hotel bookings and hotel owners managing properties.

## 2. Core Features
1. **Clerk Authentication & Session Management:** Secure sign-up, login, and session persistence.
2. **Real-time Room Search & Availability:** Date-based availability verification and multi-night pricing calculation.
3. **Stripe Checkout Integration:** Secure payment gateway handling for online room reservations.
4. **Automated Nodemailer Emails:** Instant HTML reservation confirmation receipts sent via SMTP.
5. **Hotel Owner Analytics Dashboard:** Centralized metrics overview tracking total bookings, occupancy, and cumulative revenue.

## 3. Tech Stack
* **Frontend:** React 19, Vite, Tailwind CSS v4, React Router DOM, Axios, Clerk React, React Hot Toast.
* **Backend:** Node.js, Express 5, Mongoose ODM, Nodemailer, Cloudinary, Multer, Stripe SDK.
* **Database:** MongoDB Atlas.
* **Deployment:** Vercel.

## 4. Timeline & Milestones
* **Day 1 (Plan & Scope):** Project scoping, paper wireframes, and GitHub repository initialization.
* **Day 2 (Core Structure):** Mongoose schemas, backend stub routes, frontend layout, navigation, and hero section.
* **Day 3 (Features & Polish):** Connecting frontend to backend via Axios, booking workflow, responsive adjustments, and UI polish.
* **Day 4 (Deployment & SEO):** Vercel & Render production deployment, environment variables setup, and SEO meta tags.
* **Day 5 (Demo & Case Study):** Final testing, Loom video recording, `CASE_STUDY.md` writing, and final submission.
